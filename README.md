Overview
This project retrieves, processes, and visualizes weekly petroleum stocks data from the U.S. Energy Information Administration (EIA) API. 
The script fetches data for various petroleum products (Crude Oil, Gasoline, Distillate, Ethanol, and Residual Fuel), processes it, and generates interactive visualizations using Plotly.

Features
Automated Data Retrieval: Fetches weekly petroleum stock data from the EIA API.
Multi-Year Analysis: Aggregates stock levels by week across multiple years.
Dynamic Visualization: Generates line charts and tables using Plotly to compare stock trends.
Export Capability: Saves the generated visualization as an HTML file.


Data Sources
EIA API (Energy Information Administration)
